GPIO 是什么（先建立直觉）

GPIO = General Purpose Input/Output，通用输入输出口。一句话：芯片内部的一个"可编程开关"，既能对外输出 0/1，也能读外部输入的 0/1。

  • F103 有 GPIOA~GPIOE 五组（A/B/C/D/E），每组 16 个引脚（PIN0~PIN15）
  • 每个引脚内部有一堆"可配置的电路"（MOS 管、上下拉电阻），配置成什么模式，引脚就表现成什么样
  • 后面所有外设（OLED、按键、PWM、ADC…）最终都是通过 GPIO 引脚进出芯片的
核心套路（背下来）所有 GPIO 用法只有 4 步：① 开时钟 → ② 配结构体（模式）→ ③ GPIO_Init → ④ 读写。
区别只在第 ② 步的模式和④步的读写函数。

推挽 = 两个开关一上一下。上面的开关连 3.3V（电源），下面的开关连 GND（地）。任何时候只有一个闭合：

看懂了什么推挽输出的"推"和"挽"：输出 1 = 上开关闭合，把引脚"推"到 3.3V（此时下开关断开）；输出 0 = 下开关闭合，把引脚"挽"到 GND（上开关断开）。两个方向都有强驱动能力——所以叫"推挽"。
LED 亮灭看接法上图 LED 阳极接 VCC、阴极接 GPIO——GPIO 输出 0 时电流从 VCC→LED→引脚→GND，灯亮；输出 1 时两边都是高，没电流，灯灭。这就是蓝板 LED"低电平点亮"的原因。
2
开漏输出（GPIO_Mode_Out_OD）· 对比

开漏 = 只有下开关，没有上开关。输出 1 时引脚"悬空"（靠外部上拉电阻拉到高）：

推挽 PP开漏 OD
输出 1上管闭合，引脚=3.3V（强驱动）无上管，引脚靠外部上拉
输出 0下管闭合，引脚=0V下管闭合，引脚=0V（一样）
用途LED、普通 IOI2C、电平转换、总线（多设备共线）
记忆推挽：强推强拉，普通场合首选。开漏：只能拉低，"拉高"靠别人（外部上拉）——I2C 总线所有设备都是开漏，才允许"线与"。

输入模式（上拉/下拉/浮空）· 按键电路交互

输入 = 引脚只"读"不"写"。关键是内部有没有"默认电平"：

引脚默认电平：
模式不按（默认）按下 KEY 后用途
上拉 IPU读到 1按键接地 → 读到 0按键接 GND（低有效，教程默认）
下拉 IPD读到 0按键接 3.3V → 读到 1按键接 VCC（高有效）
浮空不确定（悬空乱跳）取决于按键接哪模拟信号、外部已上/下拉
这是你 1008 踩过的坑！按键配置必须和按键另一端的接法匹配：
按键另一端接 GND → 用 IPU + 判断 ==0；
按键另一端接 3.3V → 用 IPD + 判断 ==1。
配反了 = 按了没反应（当时折腾了半小时最后发现是面包板虚接 😅）。

八种模式总览（点击卡片看解释）
输入 · 浮空 GPIO_Mode_IN_FLOATING
引脚悬空，电平由外部决定。外部没接东西时读数随机乱跳。
输入 · 上拉 GPIO_Mode_IPU
内部接上拉电阻到 VDD，默认读 1。按键接 GND 用这个。
输入 · 下拉 GPIO_Mode_IPD
内部接下拉电阻到 GND，默认读 0。按键接 3.3V 用这个。
输入 · 模拟 GPIO_Mode_AIN
引脚接模拟电路（ADC 采样用），不读数字电平。
输出 · 推挽 GPIO_Mode_Out_PP
一上一下两个开关，强推强拉。LED/蜂鸣器首选。
输出 · 开漏 GPIO_Mode_Out_OD
只有下开关，拉高靠外部上拉。I2C 总线用。
复用 · 推挽 GPIO_Mode_AF_PP
引脚交给片上外设（TIM/USART/SPI）输出。PWM 用这个！
复用 · 开漏 GPIO_Mode_AF_OD
片上外设输出 + 开漏。硬件 I2C 引脚用。
实战记忆（只记 4 个够用）LED/蜂鸣器 → 推挽输出；按键 → 上拉/下拉输入；PWM/串口 → 复用推挽；ADC → 模拟输入。
复用 = 引脚控制权交给内部外设（GPIO 自己不再读写）。

库函数三板斧（对照你的 1002 工程）
// ① 开时钟：GPIOA 在 APB2 总线上
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

// ② 配结构体：引脚 / 模式 / 速度（三要素）
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_4;
GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_PP;   // 推挽输出
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;   // 翻转速度
GPIO_Init(GPIOA, &GPIO_InitStructure);

// ③ 读写
GPIO_SetBits(GPIOA, GPIO_Pin_4);      // 输出 1
GPIO_ResetBits(GPIOA, GPIO_Pin_4);    // 输出 0
GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1);  // 读按键

LED 闪烁 = 翻转 + 延时；流水灯 = 移位

while (1) {
    GPIO_ResetBits(GPIOA, GPIO_Pin_4);   // 亮
    Delay_ms(500);
    GPIO_SetBits(GPIOA, GPIO_Pin_4);     // 灭
    Delay_ms(500);
}

按键扫描 = 消抖 + 松手检测

uint8_t Key_GetNum(void) {
    uint8_t KeyNum = 0;
    if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0) {  // 按下
        Delay_ms(20);                                      // 消抖
        while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0); // 等松手
        Delay_ms(20);
        KeyNum = 1;
    }
    return KeyNum;
}
本章要点输出三件套（SetBits/ResetBits/WriteBit）+ 读输入（ReadInputDataBit）。消抖 20ms 是经验值（机械按键抖动 5~20ms）。
!
实战坑（GPIO 相关）
① PB3/PB4 默认被 JTAG 占用PA15、PB3、PB4 复位后是 JTAG 引脚，不能当普通 GPIO。要用必须关 JTAG（GPIO_Remap_SWJ_JTAGDisable），但保留 SWD 不影响下载。你的 1002 按键就是这么修好的。
② 开时钟是第一步忘了 RCC_APB2PeriphClockCmd → GPIO 寄存器写不进，引脚完全没反应，编译还不报错——最阴的坑。
③ 速度参数GPIO_Speed 是"最大翻转速度"（2/10/50MHz），不是必须匹配外设频率。写 50MHz 通常没错，不用纠结。
