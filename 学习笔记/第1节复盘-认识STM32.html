STM32 是什么

ST（意法半导体）公司基于 ARM Cortex-M 内核的 32 位微控制器（MCU）。F103 系列用的是 Cortex-M3 内核，主频 72 MHz。

STM32 是一个大家族，常见分类：

系列内核主频定位
F0 / F1M0 / M348/72 MHz入门、低成本
F4 / F7M4 / M7180/216 MHz高性能、带 DSP/FPU
H7M7480 MHz顶级性能
G0 / G4 / WBM0+ / M4 / M4—低功耗 / 无线（蓝牙）
F103 在哪STM32F1 系列里的"中端主流款"，72 MHz、丰富外设、性价比最高——是大学教学/竞赛/入门项目最常用的型号。

SWD 是什么（你这次的薄弱点）

SWD（Serial Wire Debug） 是 ARM 设计的2 线制调试接口，专门用来给单片机下载程序 + 在线调试：

线STM32 引脚作用
SWDIOPA13数据线（双向）
SWCLKPA14时钟线（主控→芯片）
GND—必须共地
VCC—给 STLink 供电（可不接）

SWD 是 JTAG（5 线：TMS/TCK/TDI/TDO/RST）的"简化版"——只保留下载/调试必须的 2 根线，更省引脚。F103C8T6 上电默认 SWD 开，JTAG 关（需要关闭 JTAG 才能用 PA15/PB3/PB4 当普通 GPIO）。

工程小坑（你踩过）STLink 连接 STM32 时报"No target connected"——90% 是 SWDIO/SWCLK 接错引脚，记住是 PA13/PA14，不是 PA14/PA15。

薄弱点专项补课

① 程序存在哪里？（你上次没答出来）

直接答案程序（你写的 main.c 等）烧进 Flash 里。运行时从 Flash 一条条读出到 CPU 执行。
Flash 断电不丢，所以你烧写一次程序，重新上电还在跑。
存储器存什么类比掉电
Flash程序（你写的代码）电脑的硬盘不丢
SRAM运行时变量、堆栈、中间数据电脑的内存条丢
Option Bytes读保护、BOOT 配置等系统设置BIOS不丢

② SWD 是什么？（你上次没答出来）

上面已经讲清楚，记住一句话：SWD = ARM 设计的 2 线调试口，SWDIO=PA13、SWCLK=PA14。我们用 STLink V2 走 SWD 下载程序，比 JTAG 省引脚。

闪存编程（补充）STM32 的 Flash 还能"在程序里自己擦写自己"——后面如果学 IAP 在线升级、数据存储，会用到这个特性。F103 内部 Flash 擦写次数约 1 万次，所以不能频繁往 Flash 写变量（用 SRAM）。

第 1 节复盘自测卡（10 题）
1. STM32F103C8T6 用的是哪个内核？主频多少？
→ ARM Cortex-M3 内核，主频 72 MHz
2. "C8T6" 中的 C 和 8 分别代表什么含义？
→ C=48 引脚，8=64 KB Flash
3. APB1 和 APB2 时钟分别是多少？GPIO 挂哪条？
→ APB1=36 MHz，APB2=72 MHz；GPIO 挂 APB2
4. STM32 片内有几种存储器？分别存什么？断电后数据会丢吗？
→ 两种：Flash（存程序，断电不丢）、SRAM（存运行时变量/堆栈，断电丢）
5. 什么是 SWD？SWDIO 和 SWCLK 分别对应 STM32 哪两个引脚？
→ SWD = ARM 设计的 2 线调试接口（下载/调试用）。SWDIO=PA13，SWCLK=PA14
6. STM32 片内 4 大组成部分是什么？
→ 内核（Cortex-M3 + NVIC + 调试）、存储（Flash + SRAM）、总线（AHB + APB1/2）、外设（GPIO/USART/TIM…）
7. 最小系统板包含哪 5 部分？
→ 供电、晶振、复位、启动配置（BOOT）、调试接口（SWD）
8. HSE 晶振频率是多少？起什么作用？
→ 8 MHz 外部高速晶振，给系统提供主时钟源（经 PLL 倍频到 72 MHz）
9. 32.768 kHz 晶振起什么作用？
→ 给 RTC（实时时钟）提供精确的秒计时（2^15=32768，分频后正好 1 Hz）
10. "外设时钟必须先开" 的根本原因是什么？
→ STM32 默认所有外设时钟都是关闭的（低功耗设计）。要使用某个外设必须先开对应总线（APB1/APB2）时钟，否则寄存器写不进去，外设不工作。
