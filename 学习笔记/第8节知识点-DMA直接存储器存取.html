① DMA 是什么：CPU 的"搬运工" ▶

DMA（Direct Memory Access）直接存储器存取：提供外设 ↔ 存储器或存储器 ↔ 存储器之间的高速数据传输，无须 CPU 干预。

  • 没有 DMA 时：CPU 每次搬一个数据都要「读内存 → 写寄存器 → 再读」循环，搬 7 个字节 CPU 忙 7 次
  • 有 DMA 后：CPU 配置好「源地址、目的地址、长度、方向」，然后干自己的事；DMA 硬件自己搬完，搬完用传输完成中断（TC）通知 CPU
资源（PPT 100）F103 有 12 个 DMA 通道：DMA1（7 个）+ DMA2（5 个）。C8T6 只有 DMA1（7 个通道）。每个通道都支持软件触发和特定的硬件触发（每个通道固定绑定几个外设请求）。
② 外设侧 vs 存储器侧：DMA 只认「地址」 ▶

结构图左右两侧分别是 DMA 搬运的两端，每端都要配 3 个参数：

参数外设侧存储器侧示例（1014）
起始地址外设寄存器地址（如 ADC_DR、DataA）存储器地址（DataB、ADValue[]）DMA_PeripheralBaseAddr=DataA / DMA_MemoryBaseAddr=DataB
数据宽度8/16/32 位8/16/32 位Byte（uint8_t）
地址自增PeripheralInc 开/关MemoryInc 开/关都开（数组连续地址）
为什么"地址自增"这么重要搬数组时源/目的地址要自动 +1（或 +2/+4），否则每次都搬同一个地址、只覆盖第一个元素。ADC_DR 这种单个寄存器则必须关闭外设侧自增。
③ 传输计数器 + 自动重装器：搬几个？搬完怎么办？ ▶
  • 传输计数器（CNDTR）：剩余要搬的次数，每搬一次 -1，减到 0 传输结束，置位传输完成标志 TC
  • 自动重装器：Normal 模式：搬完 CNDTR=0 就停（要再次搬运需重新设 CNDTR）；Circular 模式：搬完自动把 CNDTR 重装回初值，循环不停
Normal 模式的大坑Normal 模式下搬完一次，CNDTR 变 0，DMA 通道自动禁用。第二次搬运必须：DMA_Cmd(Disable) → DMA_SetCurrDataCounter(重设计数) → DMA_Cmd(Enable)。这就是 1014 里 MyDMA_Transfer 每次都重设的原因。
④ 触发方式：什么时候开始搬？ ▶
  • 软件触发：M2M=1（存储器到存储器）时用。配置完 DMA_Cmd(ENABLE) 后立即开始搬运。1014 的 DataA→DataB 就是这种
  • 硬件触发：M2M=0（外设↔存储器）时用。要等外设发出请求信号才搬一次。如 ADC 转换完成 EOC → 自动触发 DMA 把 ADC_DR 搬走；串口收到数据 RXNE → 自动触发 DMA 搬运
ADC+DMA 为什么绝配ADC 多通道扫描，数据寄存器只有 1 个、会覆盖 —— 让 DMA 在每次 EOC 后把 ADC_DR 自动搬进数组，CPU 一次都不用管。这正是 107 页第二个实验。
⑤ 开关控制 EN：最后的开关 ▶

结构图右下角开关控制对应 DMA_Cmd(DMAx_Channelx, ENABLE/DISABLE)。

DMA_Cmd(DMA1_Channel1, DISABLE);                 // 先关（改配置前必须关）
DMA_SetCurrDataCounter(DMA1_Channel1, MYDMA_size); // 重设传输计数器
DMA_Cmd(DMA1_Channel1, ENABLE);                  // 再开（开始搬）
铁律改 DMA 配置前必须先 DISABLE，改完再 ENABLE。在使能状态下改配置会导致意外行为。

// MYDMA_Init：把结构图「两侧地址 + 中间控制」全部配好
void MYDMA_Init(uint32_t Addr_A, uint32_t Addr_B, uint16_t Size)
{
    MYDMA_size = Size;
    RCC_AHBPeriphClockCmd(RCC_AHBPeriph_DMA1, ENABLE);  // 开 DMA1 时钟（AHB 总线！）
    DMA_InitTypeDef DMA_InitStructure;

    // 左侧：外设侧配置
    DMA_InitStructure.DMA_PeripheralBaseAddr = Addr_A;   // 外设地址 = DataA
    DMA_InitStructure.DMA_PeripheralDataSize = DMA_PeripheralDataSize_Byte; // 数据宽度 8位
    DMA_InitStructure.DMA_PeripheralInc = DMA_PeripheralInc_Enable; // 地址自增

    // 右侧：存储器侧配置
    DMA_InitStructure.DMA_MemoryBaseAddr = Addr_B;      // 存储器地址 = DataB
    DMA_InitStructure.DMA_MemoryDataSize = DMA_MemoryDataSize_Byte;
    DMA_InitStructure.DMA_MemoryInc = DMA_MemoryInc_Enable;

    // 中间：方向 + 计数 + 重装 + M2M
    DMA_InitStructure.DMA_DIR = DMA_DIR_PeripheralSRC;  // 外设是源（外设→存储器）
    DMA_InitStructure.DMA_BufferSize = Size;           // 传输计数器初值 = 4
    DMA_InitStructure.DMA_Mode = DMA_Mode_Normal;      // 普通模式（搬完停）
    DMA_InitStructure.DMA_M2M = DMA_M2M_Enable;       // 存储器到存储器 → 软件触发
    DMA_InitStructure.DMA_Priority = DMA_Priority_Medium;

    DMA_Init(DMA1_Channel1, &DMA_InitStructure);      // 全部写进通道1
    DMA_Cmd(DMA1_Channel1, DISABLE);                 // 开关控制：先关
}

// MyDMA_Transfer：开关控制 + 重设计数 → 软件触发搬运 → 等 TC
void MyDMA_Transfer(void)
{
    DMA_Cmd(DMA1_Channel1, DISABLE);
    DMA_SetCurrDataCounter(DMA1_Channel1, MYDMA_size);  // 重装传输计数器
    DMA_Cmd(DMA1_Channel1, ENABLE);                  // 开 → M2M 立即开始搬
    while(DMA_GetFlagStatus(DMA1_FLAG_TC1) == RESET); // 等传输完成标志
    DMA_ClearFlag(DMA1_FLAG_TC1);                  // 清标志
}
对应关系两侧地址（PeripheralBaseAddr=DataA / MemoryBaseAddr=DataB）→ 数据宽度/自增 → DIR 方向 → 传输计数器 BufferSize/SetCurrDataCounter → 自动重装 Normal → M2M 软件触发 → DMA_Cmd 开关控制 → 等 TC 标志。整个结构图从左到右、从下到上全覆盖。

其他要点 数据宽度与对齐、通道、坑 ▶

数据宽度与对齐（PPT 105）

DMA 每端的数据宽度可独立设 8/16/32 位。宽度不同时对齐规则：

  • 源 8 位 → 目的 16 位：高位补 0
  • 源 16 位 → 目的 8 位：只保留低 8 位（高位丢弃）
  • 宽度一致（如两边都 16 位）：直接搬，无对齐问题
结论最省心：两端宽度设成一样。ADC 12 位结果用 uint16_t 数组 + HalfWord 宽度。
