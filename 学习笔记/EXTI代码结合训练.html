用途想配置 EXTI 的触发方式为「下降沿触发」，应该写？
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
NVIC_InitStructure.NVIC_IRQChannel = EXTI0_IRQn;
TIM_Cmd(TIM2, ENABLE);
用途想把 PB14 引脚接到 EXTI 线 14 上，应该写？
EXTI_InitStructure.EXTI_Line = EXTI_Line14;
NVIC_InitStructure.NVIC_IRQChannel = EXTI15_10_IRQn;
GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource14);
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
用途想让 GPIOA 的推挽输出引脚 PA4 输出低电平，应该写？
GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_4);
GPIO_ResetBits(GPIOA, GPIO_Pin_4);
GPIO_SetBits(GPIOA, GPIO_Pin_4);
GPIO_WriteBit(GPIOA, GPIO_Pin_4, Bit_SET);
用途在中断服务函数开头，想确认是不是 EXTI_Line14 触发了这次中断，应该写？
if (EXTI_GetITStatus(EXTI_Line14) == SET)
EXTI_ClearITPendingBit(EXTI_Line14);
GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_14);
TIM_GetITStatus(TIM2, TIM_IT_Update);
用途想让 PB0 的 EXTI 中断有「抢占优先级 1、响应优先级 2」，应该写？
EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
NVIC_InitStructure.NVIC_IRQChannelSubPriority = 2;
NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
用途中断里处理完了，想让 CPU 不再认为这个中断"还在挂起"，应该写？
EXTI_ClearITPendingBit(EXTI_Line0);
EXTI_GetITStatus(EXTI_Line0);
NVIC_Init(&NVIC_InitStructure);
GPIO_SetBits(GPIOB, GPIO_Pin_0);

总结：函数 ↔ 硬件模块 对照表（背下来）
硬件模块配置函数 / 代码对应寄存器（了解即可）
时钟门控RCC_APB2PeriphClockCmd(..., ENABLE)RCC_APB2ENR（开外设时钟）
GPIO 模式GPIO_Init(端口, &结构体)GPIOx_CRL/CRH（配置模式速度）
引脚→EXTI 映射GPIO_EXTILineConfig(端口源, 引脚源)AFIO_EXTICR1~4（选哪根 GPIO）
边沿检测EXTI_Init(&结构体) 配 TriggerEXTI_RTSR/ FTSR（上升/下降沿）
中断屏蔽EXTI_LineCmd = ENABLEEXTI_IMR（屏蔽寄存器）
NVIC 使能/优先级NVIC_Init(&结构体)NVIC_ISER/ NVIC_IPR
判断标志EXTI_GetITStatus(线)EXTI_PR（挂起寄存器）
清除标志EXTI_ClearITPendingBit(线)EXTI_PR 写 1 清除
一条主线：每段配置代码 = 在设置一个硬件模块的寄存器。配置顺序就是信号流经的顺序：
GPIO(CRL/CRH) → AFIO(EXTICR) → EXTI(RTSR/FTSR/IMR) → NVIC(ISER/IPR)，中断发生后再读/清 EXTI_PR。
