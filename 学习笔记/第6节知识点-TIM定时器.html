① 四大时钟源：定时器的"心跳"从哪来 ▶

定时器是个计数器，但计数用的"脉冲"必须从某个时钟源来。F103 通用定时器（TIM2~4）有 4 种时钟源：

时钟源含义典型应用对应代码
RCC 内部时钟CK_INT = 72MHz（最常用）普通定时中断TIM_InternalClockConfig(TIMx)
ETR 外部时钟PA0 引脚输入的方波（时钟模式2）外部信号当计数源TIM_ETRClockMode2Config(...)
ITRx 其他定时器用别的定时器的更新事件作计数源定时器级联、扩时基从模式相关配置
TIx 捕获通道CH1/CH2 引脚输入（时钟模式1）捕获通道边沿计数从模式 + TI 选择
结论我们学 6-2 用的是 RCC 内部时钟，所以代码里只有一行 TIM_InternalClockConfig(TIM2);。其他三种是扩展玩法，结构图里"梯形选择器"就在干这件事 —— 选哪路作为 CK_PSC。
② 预分频器 PSC：把时钟"降速" ▶

72MHz 太快了（1 秒 7200 万次），根本用不上。PSC 把 72MHz 分频后再送给 CNT。分频系数 = PSC+1。

  • PSC 写 0 → 1 分频 → CK_CNT = 72MHz（不降速）
  • PSC 写 71 → 72 分频 → CK_CNT = 1MHz（最常用，1µs 数一次）
  • PSC 写 7199 → 7200 分频 → CK_CNT = 10kHz
为什么 +1PSC 寄存器写 0~65535，对应 1~65536 分频。代码里写 TIM_Prescaler = 7200-1 表示 7200 分频 —— "-1" 不是减 1，是把"实际分频系数"翻译成"寄存器值"的固定写法。
③ 计数器 CNT 与自动重装器 ARR：溢出产生更新事件 ▶

CNT 在 CK_CNT 的每个脉冲 +1（向上计数），数到 ARR 那个数就溢出归零，并产生一次更新事件（UEV / U）。

  • ARR 写 9999 → CNT 走 0~9999 共 10000 次后溢出
  • 影子寄存器：ARR 实际是有"预装载"的，修改 ARR 要等下一个 UEV 才生效（这就是 60/61 页"有/无预装时序"的差别，暂不深究）
决定溢出频率每秒钟溢出几次 = CK_CNT / (ARR+1)。再取倒数就是溢出周期（两次中断的间隔）。
④ 运行控制 CEN：忘了它，整个时基都不动 ▶

结构图底部有个运行控制，对应 CR1 寄存器的 CEN（Counter Enable）位。CEN=0 时 CNT 停摆，再多脉冲也数不动。

TIM_Cmd(TIM2, ENABLE);   // 内部就是 CR1.CEN = 1
第一大坑代码配得全对，但忘了 TIM_Cmd —— 定时器不跑、看不到任何现象。它是初始化最后一步。
⑤ 中断输出控制 → NVIC：UEV 怎么送到 CPU ▶

UEV（更新事件）有两个去向：

  • 直接送 触发控制器（去 DAC/ADC 或别的定时器）
  • 经过中断输出控制（DIER.UIE = 1 时）→ 送到 NVIC → CPU 跳进中断服务函数
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);   // 打开 UIE = 1（更新中断使能）
NVIC_Init(...);                              // NVIC 通道使能，CPU 才能响应
三道闸门UEV 要到达 CPU 必须三道闸门全开：① UIE=1（中断使能） ② NVIC 通道使能 ③ 全局中断开关（默认开，Cortex-M3 不需要再开）。任何一道忘了，中断不来。
↔ 一行代码 = 结构图上一个模块 ▶

把 Timer_Init 的每一行 点一下，会高亮结构图上对应的模块；反过来，点结构图模块也能高亮对应代码。

void Timer_Init(void)
{
    // ① 开 TIM2 时钟（APB1 总线）
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    // ② 选时钟源：RCC 内部 72MHz → 结构图最左侧 RCC → 选择器
    TIM_InternalClockConfig(TIM2);

    // ③ 时基单元：PSC / ARR / 计数模式
    TIM_TimeBaseInitTypeDef TimeBaseInitStructure;
    TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TimeBaseInitStructure.TIM_CounterMode   = TIM_CounterMode_Up;
    TimeBaseInitStructure.TIM_Prescaler = 7200 - 1;     // PSC 预分频
    TimeBaseInitStructure.TIM_Period    = 10000 - 1;    // ARR 自动重装
    TimeBaseInitStructure.TIM_RepetitionCounter = 0;
    TIM_TimeBaseInit(TIM2, &TimeBaseInitStructure);     // 写进时基

    // ④ 打开更新中断：UIE=1（中断输出控制闸门）
    TIM_ClearFlag(TIM2, TIM_FLAG_Update);                  // 先清残留标志
    TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);

    // ⑤ NVIC 通道使能（第二道闸门）
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    // ⑥ 启动定时器：CEN=1（运行控制）
    TIM_Cmd(TIM2, ENABLE);
}

// 中断服务函数（结构图最右侧 NVIC → CPU → 进这里）
void TIM2_IRQHandler(void)
{
    if(TIM_GetITStatus(TIM2, TIM_IT_Update) == SET){
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);   // 先清标志
        Num++;
    }
}
对应关系一句话① RCC → ② InternalClockConfig → ③ PSC/ARR/TimeBaseInit → ④ TIM_ITConfig(UIE) → ⑤ NVIC_Init → ⑥ TIM_Cmd(CEN) —— 正好对应结构图从左到右走一遍。
🔀 一个时基单元，三种玩法：PWM / 输入捕获 / 编码器接口 ▶

这是 6 章最重要的统一视角：

核心结论定时器四大功能共用同一个时基单元（PSC + CNT + ARR）。区别只在"捕获/比较通道"怎么用：

① 定时中断（基础）

只用时基单元本身。CNT 溢出 → UEV → UIE → NVIC。

时基 → NVIC

② 输出比较 PWM（6-3/6-4）

时基单元 + 输出比较单元：CNT 与 CCR 比较 → REF → 极性选择/输出使能 → GPIO 输出 PWM。

时基CCROCGPIO

③ 输入捕获（6-5/6-6）

时基单元 + 输入捕获单元：GPIO → 滤波器 → 边沿检测 → CCR1 拍照；配合从模式 Reset自动清零 CNT。

时基CCR1从模式

④ 编码器接口（6-7/6-8）

时基单元 + 编码器接口：双路 GPIO → 滤波器 → 边沿检测 → 硬件正交解码 → CNT 自动加减。

时基TI1+TI2编码器模式

PPT 58 页：预分频器时序（理解 PSC）

PSC 是 16 位计数器：每来一个 CK_PSC 脉冲 PSC+1，数到 PSC（写入值）就归零并输出一个 CK_CNT 脉冲。所以"写 N" = "N+1 分频"。

  • 第一次预分频的"前 N 个"脉冲不计数（PPT 58 图的"缓冲"段），从第 N+1 个开始
  • PSC 修改后也要等下一轮才生效（缓冲机制）

PPT 60/61 页：计数器无预装 vs 有预装

  • 无预装：直接写 CNT 立即生效（PPT 60）
  • 有预装（影子寄存器）：写 ARR/PSC 立即进"预装载寄存器"，要等下一次 UEV 才同步到影子（PPT 61）—— 这样可以避免中途改 ARR 导致周期错乱
结论平时我们不需要主动管预装，使用库函数 TIM_TimeBaseInit 默认就是带预装的。如果要立即生效，用 TIM_PrescalerConfig + TIM_PSCReloadMode_Immediate。

面试一句话 / 标准答法

  • 定时器是什么：硬件计数器，对输入时钟计数，达到设定值时触发中断或事件。
  • 比软件 Delay 好在哪：不占 CPU，定时期间 CPU 可干别的。
  • 四大功能统一记忆：共用时基单元，区别在通道用法（OC / IC / Encoder）。
  • 如何用 TIM 测频率：输入捕获 + 从模式 Reset，Freq = 1MHz / CCR1（前提是 PSC=71 让计数频率为 1MHz）。
  • 编码器接口优势：硬件正交解码，不丢脉冲、不占 CPU，比 EXTI 软件方案可靠。

速背口诀

六句口诀（按 57 页从左到右） ① RCC 开时钟（APB1 勿错）→ ② 选源 InternalClock（默认 RCC 内部）→ ③ TimeBaseInit 写 PSC+ARR（算好溢出时间）→ ④ TIM_ITConfig 开 UIE（中断闸门）→ ⑤ NVIC_Init 通道使能（CPU 闸门）→ ⑥ TIM_Cmd 开 CEN（最后一步忘就跑不动）
